# 学生档案管理系统（v8）

> 25 级汽修一班学生档案管理系统 · Tkinter 桌面应用  
> 适用于：Windows（推荐），也可在具备桌面环境的 Linux / macOS 上运行。

---

## v8 新增

- **家校沟通滚动登记**：沟通记录独立成表，按「日期 / 方式 / 对象 / 主题 / 内容 / 家长反馈 / 后续跟进 / 记录人」逐条追加，历史不改写。入口有两处：首页「家校沟通」（全班台账，选学生连续登记）、学生画像「沟通记录」页（单个学生）。旧的「最近一次谈话时间 / 谈话内容」会自动迁入台账，并在每次登记后回写，导出 Excel 仍能取到。
- **学生情况一键生成**：学生画像「情况报告」页或底部「生成学生情况」按钮，按该生档案、历次成绩、沟通记录生成四段式分析——学生信息概况 / 优势与短板 / 家校沟通注意点 / 管理注意点。
  - 离线生成：内置规则引擎，不联网、结果可解释；
  - 模型生成：接入任意 OpenAI 兼容接口（DeepSeek、通义千问、智谱、Kimi、OpenAI…），在「模型设置」里填地址、模型名、Key 即可，Key 只存本机 `ai_config.json`；
  - 复制提示词：把同一份学生数据复制走，可直接贴到 WorkBuddy 等对话里生成；
  - 生成结果自动存入档案，可回看、导出 TXT。
- **批量报告**：首页「批量报告」按班级一次性生成全班情况报告，可导出 Excel（总览 + 全文两页）。

## 功能概览

- **Excel 导入/导出**：批量导入学生档案，支持选择列导出，可导出筛选结果或全部数据。  
- **列管理**：支持新增列、删除列、列分类（按大类筛选列、配置列归属）。  
- **查询筛选**：
  - 姓名模糊搜索。
  - 按列大类 → 列名 → 列值三级筛选。
  - 清空筛选后恢复全量数据。  
- **学生画像**：首页只显示基本信息，双击学生行打开画像窗口——顶部画像卡、学业画像（考试批次 → 总分/名次 → 单科）、三张成绩趋势折线图、沟通记录、情况报告、分类字段编辑。  
- **数据库持久化**：数据存储在本地 SQLite（`student_database.db`），避免 Excel 导入导出造成的信息丢失。  
- **状态提示**：状态栏实时显示当前数据量、筛选状态、导入导出进度等。

## 环境要求

- Python ≥ 3.8
- 依赖库：
  - `pandas`
  - `openpyxl`
  - `tkinter`（Windows 自带，Linux 需安装 `python3-tk`）
  - `matplotlib`（成绩趋势折线图，缺失时自动降级为文字提示）
- 操作系统需支持 GUI。

## 快速开始

1. **克隆/下载代码**

   ```bash
   git clone <your-repo-url>
   cd <project-folder>


   常见操作指南
1. 导入学生 Excel
点击 导入Excel。
选择含 学号 列的 Excel 文件（支持 .xlsx/.xls）。
若列已存在会提示覆盖，新增列会提示确认。
完成后自动刷新界面。
2. 导出学生 Excel
点击 导出Excel。
若当前处于筛选状态，可选择导出“筛选结果”或“全部数据”。
勾选需导出的列，学号 默认勾选且不可取消。
选择保存路径后导出。
3. 列分类管理
点击 列分类。
可新增、重命名、删除列大类。
可将任意列归属到指定大类，用于筛选和详情页分组。
4. 学生详情编辑
在表格中双击学生行。
弹出详情窗口，按分类分标签显示字段，支持修改保存。
